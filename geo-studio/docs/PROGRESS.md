### Phase 7 统一验收标准

- 同品牌同题集两次跑批结果波动可解释（非随机） → 可信度分级 + 评分建议
- 跑批结果可标记可决策级别（business-ready / partial / demo） → ✅
- 低分项可生成可执行建议（不是泛告警） → ✅
- 初稿生成后可见验证反馈（提及/准确性方向） → ✅
- 分发动作可在后续趋势中观察方向性变化 → ✅
