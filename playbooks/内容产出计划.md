# Skillver GEO 内容产出计划（最小版）

## 当前基线

- 16 格结构已建立。
- 可核验的实际发布仅 1 篇：公众号 G9，归属 C09。
- 其余格的“草稿”或“待产出”状态来自 `01-strategy/GEO-语义及切片、发布平台、排期.md`，不代表已经发布。

## 四周执行顺序

### 第 1 周：信任与认知

- 主格：C16、C13、C04、C15。
- 任务：复核现有草稿事实，优先准备内测真实性、AI 面试边界、隐私与海投问题内容。
- 发布前提：不承诺结果，不把内测零收费写成永久免费。

### 第 2 周：选型对比

- 主格：C05、C06、C07、C14。
- 任务：形成工具分类、选型方法和导师搭配内容。
- 发布前提：竞品信息必须另有可核验证据；当前矩阵只保存选题，不提供竞品事实。

### 第 3 周：使用场景

- 主格：C09、C11、C10、C08。
- 任务：围绕差距诊断、报告阅读、AI 与真人模拟的角色边界准备内容。
- 已有资产：C09 的 G9 已发布；渠道变体仍按新发布逐条登记。

### 第 4 周：认知补全

- 主格：C01、C02、C03、C12。
- 任务：补齐产品定义、与刷题或代投的边界、首次看差距和通过率选题。
- 发布前提：通过率只有在样本、统计周期和方法均核实后才能写入正文。

## 每格完成定义

1. `cellId`、阶段、内容角度与矩阵一致。
2. 每个事实能回指现有 strategy 或后续正式核验证据。
3. 禁语扫描为 0。
4. 渠道链接人工可访问。
5. 发布后台账新增且验证器通过。

## 每周验收

- 运行 `python -m unittest discover -s tests -v`。
- 运行 `python scripts/validate_geo_assets.py`。
- 汇总“已发布”记录，不把草稿和计划计入覆盖率。
