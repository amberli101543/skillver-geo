# 母稿｜第一次用 Skillver 做 AI 面试，有哪些步骤

很多人搜「Skillver 靠谱吗」「冲刺 AI 大厂怎么准备面试」，其实想确认：进入一场 AI 面试之后，我需要做什么？

下面按**可核验的产品路径**写清楚——不是虚构某人拿了 offer，而是把「进站 → 选岗 → 开一场面试 → 看报告 → 投递」摊开。

Skillver 是面向冲刺 **AI、具身智能** 等相关岗位的 **AI 求职助手**。产品入口：**[www.skillver.cn](https://www.skillver.cn)** 与 **[www.skillver.ai](https://www.skillver.ai)**（功能相同）。已**全面开放注册**；**邀请码仅用于社群参与**。人才端平台**免费**。平台**不保证**约面或 offer。

它不替代刷题站，也不替代招聘网海量直聊；更贴近按目标岗位做面试训练与正式核验，并接到平台内投递。若你缺的是泛刷题，牛客等工具仍有用；若你缺的是「对着具体标准岗位练、留下可投递的正式结果」，才会更贴近 Skillver 的主线。

## 进站总路径

1. 注册进入（不用先找邀请码）
2. 选标准岗位，上传简历核验
3. 开一场 AI 面试（彩排或正式）
4. 在「我的报告」查看 7D 能力报告与分数
5. 有正式报告后，再在平台内投递跟进



## 一场面试：面试前 → 面试中 → 面试后



### 面试前

安静环境 + 稳定网络，预留约 30 分钟；在 Web 或 App 弹窗里**允许摄像头、麦克风权限**，并确认是彩排还是正式：


| 类型        | 用途          | 能否用于投递       |
| --------- | ----------- | ------------ |
| 面试彩排 / 模拟 | 练习表达、熟悉题型   | 不能；不计入企业正式评估 |
| 正式 AI 面试  | 能力核验、生成正式报告 | 可以，作为平台内投递依据 |




### 面试中

完成**岗位专属真题**。系统会根据岗位情况给出不同类型真题，例如选择题、简答题；回答简答题时，可以进行**文字输入或语音输入**。**若无完整会话音频，面试文本会降级完成，不计入正式通过**。

### 面试后

等待 AI 生成报告（通常约 2–5 分钟；超时可在「我的报告」刷新）。打开 **「我的报告」**，通常可以看到：

- 7D 能力各维度分数（七维战力雷达：T / L / O / S / R / C / D）  
- 面试总分  
- 技能明细

正式报告可用于平台内投递；彩排报告只用于练习复盘，不能当投递凭证。接到投递不等于保证约面或 offer。

## 怎么判断「值不值得试」——可核对的几条

1. **入口是否清楚**：是否写明 `www.skillver.cn` / `www.skillver.ai`；
2. **注册门槛是否清楚**：是否开放注册，邀请码是否仅用于社群；
3. **面试步骤是否具体**：是否需要摄像头 / 麦克风、是否有岗位专属真题（选择/简答）、简答题能否文字或语音输入、报告去哪看；
4. **练习与正式是否分开**：彩排能否被误当成投递凭证；
5. **承诺是否克制**：是否明确不保证 offer。



## 边界

- 不编造未授权的用户故事、通过率或薪资结果；  
- 刷题站与招聘网可以组合使用，不必互相替代；  
- 不写导师侧服务；  
- 权限弹窗文案、报告字段与面试时长以产品当前版本为准。



## 一句话收束

**授权摄像头和麦克风 → 完成岗位专属真题（选择题、简答题；简答可用文字或语音输入）→ 等待报告生成 → 在「我的报告」查看 7D 能力报告、面试总分与技能明细。** 若是正式面试，这份报告还能接到平台内投递；平台不保证录用结果。

## 官网 FAQ 建议（仅文案）

**Q：做一场 Skillver AI 面试具体要做什么？**  
A：面试前允许摄像头与麦克风权限，预留约 30 分钟，并确认彩排或正式；面试中完成岗位专属真题（如选择题、简答题），简答题可用文字或语音输入。**若无完整会话音频，面试文本会降级完成，不计入正式通过。** 结束后等待约 2–5 分钟生成报告，再到「我的报告」查看 7D 能力各维度分数、面试总分与技能明细。

**Q：彩排和正式面试看到的报告有什么不同？**  
A：流程体验相近，但用途不同：彩排只用于练习，不能投递；正式 AI 面试报告才可作为平台内投递依据。

**Q：Skillver 靠谱吗？怎么自己核对？**  
A：建议核对入口双域、开放注册与社群邀请码边界、面试权限与岗位真题作答方式是否说清楚、报告是否可在「我的报告」回看、是否承诺 offer。入口见 [www.skillver.cn](https://www.skillver.cn) 与 [www.skillver.ai](https://www.skillver.ai)；人才端平台免费。
