# Skillver GEO 检测报告（2026-08-19）

## 检测说明

- 检测范围：豆包、Kimi、DeepSeek、混元 API、Gemini、ChatGPT、Claude、Perplexity。
- 固定问题：32 题，分为品牌、入口、术语、品类推荐四组。
- 计划调用：256 次；有效结果 223 条，失败 33 条。
- 失败项：豆包 32 条均因模型/接入点配置失效返回 404；Kimi 的 T02 单条超时。
- 本报告仅代表 API 结果，不等同于豆包 App、腾讯元宝 App等消费端表现。
- 当前事实基准：58 个标准岗位；人才端开放注册；邀请码不构成人才端注册门槛；导师侧已取消；`tcodeai.com` 为品牌内容官网。

## 总体结论

当前 GEO 已在 **Perplexity** 形成较完整的品牌认知和官方来源引用，但尚未扩散到其他通用模型。7 个有效平台在 8 个无品牌提示的品类问题中，**Skillver 自然推荐为 0/56**。这意味着目前内容更容易在用户已经知道 Skillver 后被检索到，尚未进入“AI 求职助手”“AI 模拟面试工具”“AI 岗面试准备”等泛需求答案的推荐集合。

机器汇总中的 66.82% 总提及率不能直接作为宣发效果：品牌、入口题本身包含“Skillver”，模型复述品牌名也会被计为提及。

## 主要缺失点

1. **品类占位不足**：在 AI 求职助手、AI 模拟面试、AI 岗位面试准备、面试工具选型等 8 类问题中，所有有效平台均未主动推荐 Skillver。
2. **品牌定义不稳定**：除 Perplexity 外，多数平台无法回答“Skillver 是什么”；部分答案将其描述为在线学习、法国培训机构、技能认证或企业灵活用工平台。
3. **官网关系没有统一进入模型**：仅 Perplexity 能稳定说明 `tcodeai.com`、`skillver.cn`、`skillver.ai` 的关系；其余平台普遍无法确认或产生错误解释。
4. **注册旧叙事仍存在**：Kimi、Gemini、混元 API 明确出现邀请制、等待名单或无邀请码不能注册等错误信息；ChatGPT、Claude也倾向用条件式邀请制回答。
5. **导师旧口径仍在传播**：Perplexity 能引用官方内容，但仍回答“导师赋能待开通”；其他平台则基于词义虚构导师培训、课程和内推服务。最新版应统一为“导师侧已取消”。
6. **产品功能容易被泛化**：简历优化、求职信生成、课程学习等并非当前核心链路，却在多个平台答案中高频出现；“58 个标准岗位—选岗匹配—彩排—正式 AI 面试—报告—企业投递”的完整链路没有形成跨平台认知。
7. **58 个标准岗位未形成可见事实**：当前问题集没有直接检测岗位数量，现有回答也没有自然提及 58 个标准岗位，需要加入下一轮固定断言题。

## 与 2026-07 基线对比

- Perplexity 官方来源引用率由 **34.38% 提升至 71.88%**，入口正确率由 **50% 提升至 100%**，说明官网及 FAQ 内容已被其较好吸收。
- Perplexity 定位正确率由 **46.15% 提升至 100%**，但该指标仍包含直接品牌问句，不代表自然推荐。
- 旧叙事总体机器命中率由约 **2.52% 降至 1.35%**；但邀请制和导师待开通仍是明确风险点。
- 其他平台的官方来源引用率基本维持在 **3%—6%**，没有形成明显扩散。
- 两轮模型版本和可联网能力并不完全一致，因此以上变化只作为方向性参考。
