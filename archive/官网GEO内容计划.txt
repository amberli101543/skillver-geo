## 建议优先准备（按重要性排序）

| 优先级   | 内容               |
| ----- | ---------------- |
| ⭐⭐⭐⭐⭐ | 品牌定义（品牌是什么）      |
| ⭐⭐⭐⭐⭐ | 产品介绍（每个产品）       |
| ⭐⭐⭐⭐⭐ | T-Code 协议        |
| ⭐⭐⭐⭐⭐ | 白皮书（Research）    |
| ⭐⭐⭐⭐  | FAQ（30～50 个问题）   |
| ⭐⭐⭐⭐  | 解决方案（Solutions）  |
| ⭐⭐⭐⭐  | 案例（Case Studies） |
| ⭐⭐⭐   | 文档（Docs）         |
| ⭐⭐⭐   | 更新日志（Changelog）  |
| ⭐⭐    | Blog             |
| ⭐⭐    | 媒体资源（Media Kit）  |

**把官网当成一个“知识库”而不是“宣传册”。** 未来官网的主体内容应该来自四类资产：**产品定义（Product）+ 协议（Protocol）+ 研究（Research）+ 文档（Docs）**，它们会成为 AI 最容易理解和引用的内容；其他页面（案例、解决方案、FAQ）则负责不断补充可信证据和具体场景。
