# Skillver 小红书 & 知乎渠道增长运营方案

> 定位一句话：Skillver——中国优秀人才的 AI 求职助手。
> 本方案目标：在产品 **全面开放注册；邀请码仅用于赛事参与**阶段，用内容把「我很强」变成"可验证、可对比、可投递"的认知资产，沉淀目标人才、引导官网注册，并跑通一个**可自我增长的内容飞轮**。
>记忆点回归"固定模板+口头禅+统一声音"。

> **关于负鼠帖的正确归因**：它的高点击与高分享来自"负鼠表情包"当时是平台热门梗（蹭热点效应）。可复用的经验是**"借势热点能快速破圈、带来分享"**，而不是"去做一个吉祥物"。同时它人均停留只有 4 秒——印证了**热点只负责"破圈拉新"，留人和转化要靠干货承接**。

### 1.3 五个关键结论

1. **干货是地基**：高收藏 + 长停留 + 涨粉，且精准吸引目标人才，对应产品的"面试彩排/七维战力"核心卖点。
2. **痛点是流量**：口语化痛点标题撬动评论与观看率，是放大曝光的杠杆。
3. **热点是破圈**：借势平台热门梗/行业节点能拿到高点击+高分享，但必须**用 Skillver 相关的角度承接**，否则来的流量留不住。
4. **品牌要包装**：硬广被压制，品牌信息要藏在"干货/真实体验/UGC"里。
5. **稳定度决定权重**：6/19–6/21 停更三天曝光跌到个位数——账号权重来自"持续输出垂直内容"，断更即掉权重。

## 二、增长战略：定位、分工与飞轮

### 2.1 账号定位与差异化（无 IP，靠"模板+口头禅+声音"建记忆点）

**一个核心人设：懂 AI、懂面试的"求职搭子"。**
- 一半是**内行专家**：能讲 Rust / CUDA / MLOps / 架构面试的真东西（对应 10000+ 题库 + 七维战力体系），建立专业信任。
- 一半是**陪伴搭子**：懂海投石沉大海、面试卡壳、简历被刷的痛，说人话、不端着。

**记忆点不靠 IP，靠三件可复用的资产（落地方法论"固定封面风格 / 口头禅"）：**
1. **固定封面模板**：统一主色 + 固定字体 + 固定版式（大字报结论式）。
2. **标志性视觉符号**：把产品自带的**"七维战力"做成账号反复出现的视觉签名**——product-native、可复用、又天然差异化（市面求职号没有"可视化能力评估"这个符号），且每次出现都在强化产品卖点。**这不是 IP，是把产品功能符号化。**
3. **口头禅 / slogan**：固定一句签名口吻反复用，例如 收尾统一署名"——你的 AI 求职搭子"，或开篇句式"别再'感觉自己行'了"。（建议从 2–3 句里 A/B 测出最顺口的一句固定下来。）

> 差异化逻辑：市面求职号要么是"鸡汤面经号"、要么是"硬核技术号"。Skillver 的位置是**"硬核但有温度的 AI 求职搭子"**——只有它能同时给出真技术干货和**可验证的能力证明（七维战力 + 面试报告）**，这是别人抄不走的内容资产。

### 2.2 双平台分工

| | 小红书（广度·破圈） | 知乎（深度·权威） |
|---|---|---|
| 平台属性 | 生活搜索工具 + 经验分享社区 | 专业问答 + 深度讨论 |
| 受众 | 学生 / 早期求职者 / 泛 AI 岗，技术子集 | 大模型/Infra/Agent 工程师等深度技术人才 |
| 内容主轴 | 痛点共鸣 + 面经干货合集 + 热点借势 + 体验种草 | 长文技术拆解 + 高赞问题作答 + 行业洞察 |
| 主要目标 | 涨粉、起量、内测申请 | 建立"信得过"的专业权威、沉淀高质量人才 |
| 转化动作 | 评论关键词 / 私信领邀请码 | 文末软植入 + 留资引导 |

**协同打法**：一个技术选题，知乎写深度长答（证明题库与专业度）→ 小红书做"3 图速览版"合集（截流广度受众），一鱼两吃。

### 2.3 自我增长飞轮（本方案的核心引擎）

```
①高价值干货  →  高收藏/高停留/高完读  →  平台判优、加大推荐（曝光↑）
                                                        ↓
④用户真实面试报告/Offer故事(UGC)  ←  ⑤用户使用Skillver内测
        ↑（最强"可验证能力证明"内容）                    ↑
③热点借势 → 高点击/高分享 → 破圈拉新  →  ②产品种草转化 → 内测申请/邀请码
   （用干货+痛点把破圈来的流量"接住"）
```

**为什么这个飞轮会自转**：Skillver 的产品本身就在生产**全平台最高信任度的内容**——真实的 AI 面试报告、七维能力向量、真实 Offer 故事。方法论反复强调"真实可信"，产品恰好承诺"可核验"。**用户用得越好，产出的真实证明越多，证明又变成最能打的内容，内容再带来新用户**。这是 Skillver 相对其他账号不可复制的增长壁垒。其中热点只负责"破圈拉新"，干货与痛点负责"接住并留存"，缺一不可。

### 2.4 内测期转化路径（轻、不打扰）

> 关注（养粉池）→ 评论区扣关键词 / 私信领"内测邀请码"（留资）→ 引导至落地页 / 进内测群（私域）→ 体验已确认开放的环节（导师服务状态另行核实）→ 产出面试报告 / Offer → 自愿成为 UGC 素材 → 回流内容

每篇帖子结尾**必须有行动指令**（方法论："结尾要有行动指令"），按笔记类型给不同 CTA（见第四节）。

## 四、执行规范：可复制的爆款公式（落地方法论）

### 4.1 标题公式（每篇从中选一）
- **戳痛点 + 给方案**：「海投200份0回复，问题其实出在第一步」
- **身份认同 + 场景化**：「大模型岗面试，被问'你真做过Agent吗'的瞬间」
- **数字 + 结果**：「面了8家AI公司，我把高频题压成了8道」
- **具体有冲击力 / 适度标题党**：「90%的人都在'伪造'大模型经验」（引流帖可用）

### 4.2 封面规范（修复 -33% 点击率，最高优先级）
- 统一模板：固定主色 + 固定字体 + 固定版式（建立记忆点）。
- 标志符号：干货/体验帖尽量带上**"七维战力雷达图"视觉**，强化辨识度与卖点。
- 高信息密度：多用**拼图、前后对比、步骤拆解、合集清单**（方法论指定形式）。
- 大字报核心结论 / 数字，图片高清，3 秒能看懂"这帖对我有用"。

### 4.3 正文结构
- **前三行抛核心**：直接给最大亮点 / 最诱人结果，留住用户。
- 口语化、短段落、多分行；用表情符号调节节奏、突出重点（适度）。
- 体现**真实个人体验**（"我亲自测了""我面试时…"），增加可信度与亲和力。
- 结尾固定**口头禅署名**（如"——你的 AI 求职搭子"）强化记忆点。

### 4.4 发布时间（停止早上6点发布）
固定在四个流量窗口：**通勤 8–10 点 / 午休 12–14 点 / 下班 18–20 点 / 睡前 21–23 点**。
- 技术干货 → 午休 / 睡前（深度阅读时段）
- 痛点 / 热点 → 通勤 / 下班（碎片刷+情绪共鸣时段；热点贵在快，热度起来即发）

### 4.5 互动 SOP（拉账号权重）
- 发布后 1 小时内全程在线回评论（方法论："对评论回复要真诚"）。
- 痛点帖埋"钩子问题"引导用户对号入座留言。
- 每周固定 1 篇**互动笔记**（提问 / 投票 / 评论扣关键词领资料）。

## 六、知乎专项打法

知乎重"信得过"，与产品"可核验能力证明"高度同频，是沉淀深度人才的主阵地。

1. **高赞问题截流**：盯住"大模型/Agent/Infra 面试""AI 求职""转行 AI"等高流量问题，用**真技术深度**作答——把 10000+ 题库与七维体系的专业度"露"出来，而非自夸。
2. **专栏长文立柱**：每月 1–2 篇深度长文（如"大模型岗面试的真实考察维度拆解"），可被搜索长期复用。
3. **软植入而非硬广**：文末以"我最近在用一个 AI 模拟面试工具 Skillver（内测中）……"自然带出，附内测申请方式。
4. **一鱼两吃**：知乎长答 → 小红书 3 图速览版，复用选题、双平台覆盖。
5. **节奏**：先答 3–4 个高赞问题养权重，再发首篇专栏。

## 七、热点借势机制（保证"破圈位"不空转）

由于无 IP，破圈主要靠热点借势，因此需要一套**轻量监测 + 快反**机制：

1. **每日扫一眼热点源**：小红书"发现页/话题词条/上升热点"、行业新闻（AI 公司融资/发模型/扩招）、微博与知乎热榜。
2. **判断相关性**：能否用"AI 求职 / 面试 / 能力验证"的角度自然嫁接？不能强蹭则放弃（强蹭来的流量留不住，参考负鼠帖 4 秒停留）。
3. **快反产出**：备好 1 套"热点借势封面模板 + 正文骨架"，热度起来 2 小时内出稿。
4. **承接设计**：热点帖正文务必埋一句"干货钩子"或"体验钩子"，把破圈流量导向关注/干货合集/内测。

## 八、指标与复盘

### 8.1 北极星与分层指标
- **北极星指标**：**内测有效申请数（留资）**——最贴近内测期商业目标。
- 内容健康度：封面点击率（目标先止跌回升至 20%+）、收藏率、人均观看时长。
- 资产沉淀：粉丝净增、干货合集收藏量。
- 破圈效率：热点借势帖的分享数 / 涨粉数。
- 飞轮启动：UGC 真实报告/Offer 故事产出数（第 3 周起跟踪）。

### 8.2 首月方向性目标（小基数，重在跑通形态）
- 封面点击率：从 13.8% 止跌回升至 **20%+**。

### 8.3 复盘机制
- **每周**：拉单帖数据，对照四支柱，砍掉无效形态、放大跑赢的；高赞帖二次创作。
