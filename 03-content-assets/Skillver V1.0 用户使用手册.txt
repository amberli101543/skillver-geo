产品定位与核心价值

1.1 我们为谁服务
Skillver 是中国优秀人才的“AI 求职助手”。这里的“优秀人才”，不是简历上的标签，而是真正具备 AI 时代硬实力的人：能懂模型、能用AI工具，能扛架构、能在高压面试里讲清自己的思考。他们往往来自一线院校与一线团队，目标清晰——进入以AI独角兽为代表的头部科技企业，在真正决定未来的赛道上工作。

Skillver 站在人才这一侧。我们不是冷冰冰的招聘网站，也不是只帮企业筛人的工具平台，而是一位 7×24 在线、越用越懂你的 AI 搭档：帮你看清方向、证明能力、练熟面试、对接机会，直到你拿到那份值得去的 offer。

1.2 我们解决什么问题
头部科技企业的门槛，正在从“会不会”变成“强不强、真不真”。对大模型、Agent、Infra、应用层等岗位，企业不再满足于关键词匹配。他们要看真实工程能力、系统思维、临场表达与抗压表现——而这些，恰恰是传统简历和笔试难以完整呈现的。

优秀人才因此常陷入两难：实力足够，却缺少一条“被看见、被验证、被推荐”的通道；海投无效，内推靠缘，面试准备又缺少针对性反馈。

Skillver 要填的，正是这条缝。我们用 AI 把「我很强」变成可核验、可对比、可投递的能力资产；再把这份资产，精准对接到“AI 独角兽及同梯队头部科技企业”的真实岗位。你不必在信息不对称里反复试错——助手会带你走完一条清晰主线：选方向 → 验简历 → 练面试 → 投机会 → 找导师。

1.3 AI 助手如何陪你拿到头部机会
Skillver 的人才端主线，是一条为“冲头部 offer”设计的四步漏斗：
① 选岗匹配——先锁定目标岗位，避免盲目海投。
② 面试彩排——AI 模拟与正式面试，生成七维战力报告，作为投递头部企业的硬通行证。
③ 企业沟通——结构化推进投递、约面、offer 流程。
④ 导师赋能——预约真人导师，补足 AI 无法替代的行业体感与临场策略。

Web 端与移动端已同步这一主线：agent 编排入口、抽屉式重交互、进度条可视、报告独立查阅。无论你坐在电脑前，还是在通勤路上，助手都在。

1.4 为什么头部 AI 企业愿意用 Skillver
Skillver 同时连接头部科技企业的招聘侧——但重心始终在人才：因为帮企业更准地识人，所以帮人才更稳地入场。

企业端工作台支持岗位发布、人才池检索、招聘沟通管理；人才池里的每一位候选人，背后都是一份“可解释的 AI 面试报告与七维能力向量”，而非经过包装的简历话术。对企业来说，这降低了错招成本与无效面试；对你来说，这意味着“能力本身，就是最强的推荐信”。

Skillver 采集真实的职场面试场景，采用向量匹配、KAE 技能体系与 Agent 化编排，15+ 专责智能体覆盖出题、评分、检索、职业建议等链路。持续打磨评分校准与多模态测评，目标只有一个：让头部企业信得过这份能力证明，从而更愿意打开大门。

1.5 当前阶段与承诺
Skillver 已进入 ICP 封闭内测阶段，生产环境稳定运行，移动端可供内测用户体验完整漏斗。内测期实行邀请码准入、零收费策略，让人才侧可专注验证「AI 助手是否真能缩短拿到头部 offer 的路径」。

我们诚实面对仍在持续提升的环节：评分校准精度、多模态临场感、真人辅导产品化等，都在快速迭代中。但方向不变——Skillver 要做中国优秀人才奔赴 AI 时代头部科技公司的第一助手。

快速开始

2.1 如何访问

| 端 | 方式 | 说明 |
| Web | 浏览器打开 www.skillver.ai | 推荐 Chrome / Edge 90+；Firefox 可用；手机浏览器可访问人才端 |
| Android App | 安装内测 APK（侧载） | 内测期无应用商店；安装前请卸载旧版 |
| iOS App | TestFlight（若已开通） | 与 Android 功能对齐 |

2.2 注册与登录

人才端

打开 Web 或 App，选择「人才 / 求职者」入口。

使用手机号 + 短信验证码注册或登录。

登录后进入求职助手（Web：首页对话；App：Chat 首页「小 S」）。

企业端

使用手机号 + 短信验证码注册或登录。

登录后进入招聘助手（Web）或企业底栏工作台（App）。

人才端：求职主线

人才端围绕四步漏斗 + 我的报告 设计：

① 选岗匹配 → ② AI 面试 → ③ 投递企业 → ④ 导师赋能
↓
我的报告（成果汇总）

| 步骤 | 做什么 | 产出 |
| ① 选岗匹配 | 选择目标岗位，上传简历核验 | 简历匹配报告 |
| ② AI 面试 | 模拟练习 + 正式认证 | AI 面试报告（7D 雷达等） |
| ③ 投递企业 | 浏览职位，一键投递，跟进状态 | 投递记录、约面消息 |
| ④ 导师赋能 | 预约真人导师（简历/面试/入职） | 1v1 辅导时段 |
| 我的报告 | 查看所有简历报告、面试报告、能力档案 | 非漏斗步，随时可查 |

重要术语

岗位：系统枚举的标准岗位名（49 个 AI/机器人方向），用于核验与面试。

职位：企业发布的具体招聘条目（公司 + JD + 薪资等）。

投递条件：向某职位投递前，须在该职位对应岗位下至少有 1 份正式 AI 面试报告（模拟报告不能用于投递）。

人才端：分步操作

4.1 ① 选岗匹配

Web

登录后默认在求职助手首页。

点击左侧「选岗匹配」，或在对话中说「找工作 / 选岗位」。

在卡片中选择目标岗位，或从岗位列表中挑选。

App

底栏「选岗匹配」，或 Chat 首页空态三步引导卡。

选择岗位后，系统提示下一步：上传简历 / 去面试 / 去投递（视该岗位进度而定）。

提示：每个岗位独立计进度；换岗位不影响其他岗位的数据。

4.2 简历核验（选岗匹配后）

何时做：选定岗位后，尚未通过简历核验时。

Web

侧栏进入选岗流程，或在对话中说「简历核验 / 上传简历」。

在抽屉面板中上传 PDF/Word 简历（按当前岗位）。

等待解析与核验（通常数分钟）。

在「我的报告」→ 简历匹配报告 查看结果。

App

选岗页按引导「上传简历」，或底栏相关入口。

上传文件，等待结果。

抽屉菜单「简历匹配报告」或「我的报告」查看。

结果说明

通过：可进入 AI 面试与投递链。

未通过：报告会说明是「表达/信息缺失」类问题，可按提示补充材料或先去模拟面试练习表述。

限额（内测）：简历核验不限次数。

4.3 ② AI 面试（模拟 & 正式）

两种模式

| 类型 | 用途 | 能否用于投递 |
| 模拟面试 | 练习表达、熟悉题型 | ❌ 仅本人可见 |
| 正式面试 | 能力认证、投递依据 | ✅ 可作投递与人才池依据 |

面试前准备

安静环境，稳定网络（建议 Wi-Fi）。

允许摄像头、麦克风权限（Web 浏览器或 App 会弹窗申请）。

预留 30 分钟以上不被打扰的时间（内测期部分时长门槛可能低于正式版）。

Web 操作

点击侧栏「模拟面试」，或对话中说「面试彩排 / 正式面试」。

在全屏抽屉中选择岗位、模拟或正式，开始面试。

按 AI 面试官提问语音或文字作答；界面会显示聆听/思考/提问状态。

结束后等待 2–5 分钟生成报告。

App 操作

底栏「AI面试」。

选择岗位与模拟/正式，进入面试页。

流程与 Web 相同；交卷后可从通知或「我的报告」进入。

查看报告

Web：「我的报告」（侧栏）→ 模拟 / 正式 / AI 报告详情。

App：抽屉「正式面试报告 / 模拟面试建议」，或报告中心列表。

报告含 7D 雷达图（T/L/O/S/R/C/D）、各维度分数与说明、面试对话回顾；正式报告含多智能体评分说明。

限额（内测 · 按岗位）

| 服务 | 上限 |
| 模拟面试 | 5 次 / 岗位 |
| 正式面试 | 2 次 / 岗位 |

用尽后提示「本岗位已达上限」，需换岗位或联系内测支持。

4.4 ③ 投递企业

前提：目标岗位已有正式 AI 面试报告。

Web

侧栏「投递企业」→ 进入投递工作台。

三个 Tab：

在招职位：浏览企业发布的职位，搜索、筛选。

我的投递：已投递记录与状态。

企业约面：企业的面试邀请与沟通。

在职位详情点击「投递」；之后在人职对话栏用状态按钮与企业互动（非自由聊天）。

App

底栏「投递企业」→ 同上三 Tab 结构。

投递与状态操作与 Web 对齐。

状态简述

投递 → 企业邀请面试 → 你接受/拒绝 → 持续沟通。

4.5 ④ 导师赋能

何时用：冲刺头部 offer 需要真人经验时——简历精修、面试实战、入职适应，三类导师服务可按时段预约。

Web

侧栏「内测福利」（导师相关告示）。

查看导师类型与服务时段，提交预约申请。

预约成功后按约定时间进行 1v1 辅导。

App

底栏「导师赋能」。

浏览导师列表与服务详情，提交预约。

辅导安排与消息在平台内同步。

说明：内测期导师服务免费，名额有限，按需预约。

4.6 我的报告 & 能力档案

入口

Web：侧栏「我的报告」。

App：侧栏抽屉「简历匹配报告 / 正式面试报告 / 人才能力档案」等。

内容

按岗位聚合的简历核验报告、模拟/正式 AI 报告。

7D 能力雷达及文字解读。

模拟面试报告入口与正式报告区分展示。

4.7 内测反馈

Web：左下角「内测表单」提交反馈。

App：设置中「内测表单」。

内测期无在线客服，问题请通过内测表单描述（附截图、手机号、操作步骤）。

企业端：招聘主线

5.1 入口与导航

Web

登录后招聘助手对话页 + 左侧企业工作台。

主要模块：岗位发布、人才池、招聘沟通、我的。

App

底栏四 Tab：岗位发布 · 人才池 · 招聘沟通 · 我的。

5.2 发布岗位

进入「岗位发布」。

岗位名称必须从系统 49 个标准岗位中选择（如「机器学习工程师(含传统NLP)」），不能随意填写旧称。

填写 JD、薪资、城市等信息后发布。

支持编辑 / 暂停 / 关闭已发岗位；批量导入须使用标准岗位名。

对话式发布（Web）：在招聘助手中描述需求，系统推送岗位卡片确认后发布。

5.3 查看人才与报告

人才池：浏览与岗位匹配的人才列表（脱敏信息 + 7D 摘要）。

点击候选人查看 7D 报告、技能标签、面试评语、反作弊提示（切屏次数等）。

签约前身份信息脱敏；签约后有时效内的完整查看权限。

5.4 招聘沟通

「招聘沟通」Tab 查看与各人才的对话与状态。

使用状态按钮推进流程（邀请面试、发 offer 等），非即时聊天。

跟踪投递、约面、录用进度。

5.5 企业资料

「我的」→ 企业设置：可改联系人、电话、公司简介等。

营业执照上传：按页面上传；格式与大小见提示。

公司名称、统一社会信用代码等需运营协助修改。

常见问题

Q：为什么无法投递某职位？
A：请确认该职位对应岗位下已有正式 AI 面试报告（模拟报告不算）。

Q：模拟和正式面试有什么区别？
A：模拟用于练习，报告标注非认证；正式用于投递与人才池，判分引擎相同但认证口径不同。

Q：换手机后数据还在吗？
A：在。用同一手机号登录即可；App 需重新安装内测包。

Q：Web 和 App 进度互通吗？
A：互通。同一账号在两端看到相同岗位进度与报告。

Q：面试时网络断了怎么办？
A：尽量保持 App/Web 在前台；断线过久可能中断场次，已答内容一般保留，可查看报告生成状态或重试（消耗配额规则见 §8.2）。

Q：报告多久出来？
A：通常 2–5 分钟；若超时，可在「我的报告」刷新或提交内测表单。

Q：企业端岗位名保存失败？
A：请从 49 个标准岗位下拉选择，勿使用「前端工程师」等非标准简称。

Q：App 更新后仍像旧版？
A：内测无应用商店强更，请卸载旧 APK 后安装新包。

Q：导师赋能如何预约？
A：Web 侧栏「内测福利」或 App 底栏「导师赋能」查看导师列表与服务时段，提交预约申请即可。

Q：遇到问题如何反馈？
A：人才/企业均在设置 → 内测表单提交，注明：手机号、端（Web/App）、步骤、发生时间。
